# 自治体のトレーラーハウス公式情報 自動取得

管理表（Googleスプレッドシート）に付ける Apps Script です。毎月1日から30分ごとに少しずつ動き、県・政令市・特別区・特定行政庁の公式ページを調べて「2_公式情報（クロール履歴）」に追記し、「1_自治体マスタ」のF〜J列を更新します。町村は1・4・7・10月だけ調べます。見解が変わった自治体はSlackに通知します。

## 入れ方（5分）

1. 管理表を開き、「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の中身を貼り付けて保存
3. 管理表を開き直すと、上に「自動取得」メニューが出る
4. 「自動取得」→「キーを登録」で、Claude API キー・Brave Search API キー・Slack Webhook URL を入れる（キーは登録した本人にしか見えない）
5. 「自動取得」→「関東で試運転」。初回は権限の確認が出るので承認する。関東の約110件を30分ごとに少しずつ処理し、半日ほどで終わる
6. 結果がよければ、そのままでOK。翌月1日から全国分が自動で始まる

## しくみ

- 前回のページの本文が変わっていなければ、検索もAIも使わず「変化なし」と記録する（2か月目以降はほとんどこれで済む）
- 本文が変わった・前回が無い自治体だけ、Brave Search で公式サイトのページを探し、Claude Haiku 5.5 で読む
- robots.txt で自動取得を断っているページは取らない
- 取れなかったとき（404など）は履歴にだけ残し、マスタは書き換えない
- 途中でエラーが起きたら Slack に1回だけ知らせ、次の回に同じ自治体からやり直す

## 動作確認

判定まわりは Node で確認できます：`node jichitai-crawler/test.js`
