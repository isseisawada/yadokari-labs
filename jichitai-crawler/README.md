# 自治体のトレーラーハウス公式情報 自動取得

管理表（Googleスプレッドシート）に付ける Apps Script です。毎月24日から30分ごとに少しずつ動き、県・政令市・特別区・特定行政庁の公式ページを調べて「2_公式情報（クロール履歴）」に追記し、「1_自治体マスタ」のF〜J列を更新します。町村は、Brave の無料枠（月1,000件）に収まるよう、1回の検索を900件までにして、残った枠で前回の続きから少しずつ調べます（2〜3回で一周）。見解が変わった自治体はSlackに通知します。

## 入れ方（5分）

1. 管理表を開き、「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の中身を貼り付けて保存
3. 管理表を開き直すと、上に「自動取得」メニューが出る
4. 「自動取得」→「キーを登録」で、Claude API キー・Brave Search API キー・Slack Webhook URL を入れる（キーは登録した本人にしか見えない）
5. 「自動取得」→「関東で試運転」。初回は権限の確認が出るので承認する。関東の約110件を30分ごとに少しずつ処理し、半日ほどで終わる
6. 結果がよければ、そのままでOK。毎月24日から全国分が自動で始まる
7. 次の24日を待たずに今すぐ調べたいときは「自動取得」→「今すぐ調べる（無料枠の範囲で）」

## しくみ

- 前回のページの本文が変わっていなければ、検索もAIも使わず「変化なし」と記録する（2か月目以降はほとんどこれで済む）
- 本文が変わった・前回が無い自治体だけ、Brave Search で公式サイトのページを探し（1団体1回。見つからなければ言い方を変えてもう1回）、Claude Haiku 5.5 で読む
- robots.txt で自動取得を断っているページは取らない
- 取れなかったとき（404など）は履歴にだけ残し、マスタは書き換えない
- 無料枠を使い切ったら、その回はそこで止め、Slack で知らせて次の回に続きから（先払いで残高0なので、お金はかからない）
- 途中でエラーが起きたら Slack に1回だけ知らせ、次の回に同じ自治体からやり直す
- マスタの状態が「掲載あり（県の基準）」の行は、県が建築確認をしている市町村に、県の公式の基準をあてはめたもの。町村自身のページで扱いが見つかるまで、自動取得はこの値を上書きしない
- 履歴のメモに「Claude手動調査」とある行は、自動ではなく Claude が手で公式サイトを探して書いたもの

## 動作確認

判定まわりは Node で確認できます：`node jichitai-crawler/test.js`

## ヒアリングの取り込み（Slack）

営業さんが Slack のヒアリング用チャンネルに電話メモをそのまま投稿すると、30分ごとにAIが項目ごとに整理して「3_ヒアリング履歴」に追記します。

- 相談日は投稿日時、YDK担当は投稿した人の名前で埋める
- 自治体・相談先の課・先方の担当者名・対象案件・結論のどれかが足りなければ、スレッドで聞き返す。返信が来たら同じ行に追記する
- 管理表に直接書いた行にも団体コードを付け、マスタの K〜N 列（ヒアリング件数・最新日・最新の結論・見解の変化）を毎回計算し直す

準備：Slack アプリ「Jichitai Crawler」に Bot Token Scopes の `channels:history`・`chat:write`・`users:read` を足して入れ直し、チャンネルに招待。「自動取得」→「キーを登録」で Bot Token（xoxb-）とチャンネルID を入れる。
